# COUI 风格接入

## 入口与持久化

- `data/SettingsRepository.kt`：复用 `UiStyle` 和唯一的 `appearance` DataStore；`ui_style` 仍保存枚举名称，选择顺序为 Miuix / COUI（ColorOS）/ Material Design 3。
- 现有 Miuix 无前缀键和 Material 的 `material3_` 键保持兼容；COUI 使用 `coui_` 前缀保存主题、动态色、自定义色和专辑布局。其他业务设置继续共享。
- `SettingsScreen` 继续使用原有风格下拉入口。`MainActivity` 原有 Flow 收集路径触发全局重组，`ArchiveTheme` 原有 movable content 保留页面状态，无须重启。

## 原生组件

依赖锁定为官方 Maven Central 发布的 `io.github.suqi8.coui.kmp:coui-ui:1.1.0` 和 `coui-preference:1.1.0`。

- `CouiArchiveTheme` 提供官方 `COUITheme`；使用库的颜色、字形和动态色支持。
- 在现有 `ui/designsystem` 封装中增加 COUI 分支，保持调用接口；Card 颜色和按压反馈类型在边界转换，不让业务页面依赖第三套类型。
- Scaffold、大小顶栏、滚动行为、卡片、按钮、文字、图标、设置项、开关、复选框、下拉菜单、颜色选择器、底部抽屉、底部导航和侧栏均调用官方组件。
- 歌词顶栏和滑块、更新弹窗、关于页彩蛋弹窗补充原生 COUI 分支。
- COUI 超椭圆表面、按压反馈、菜单和弹窗动画由官方组件提供。顶栏和导航栏背景模糊复用项目已有的背景采样，Android 13 以下保留实色降级。Miuix、COUI 和 Material Design 3 均支持悬浮导航和液态玻璃开关；COUI 的非玻璃悬浮栏使用官方组件，液态玻璃复用现有实现并读取当前风格的主题。

## 凝光材质

COUI 的非液态玻璃悬浮底栏和工具栏按钮共用 `couiFrostedSurface`：26dp 高斯模糊、深浅色独立底色透明度、顶部细亮边、底部宽反光，以及轻微主色扩散阴影。标准底栏沿用相同底色与反光，去除悬浮阴影。

新材质仅用于按钮与底部栏。卡片、侧栏和顶部标签胶囊保持原来的样式，壁纸模糊仍由独立的卡片模糊开关控制。选中的浮动导航入口使用主色图标与浅色底衬。关闭模糊或低于 Android 13 时仍保留实色表面与边缘质感。

COUI 顶栏在列表顶部时与页面背景一致，向下浏览后以 180ms 淡入底色与模糊，回到顶部时淡出。滚动观察器只记录列表消耗的距离，不拦截滚动；大小顶栏及横屏紧凑顶栏共用该表现。

## 横屏与宽屏适配

COUI 的横屏规则参考官方 COUI / Miuix 示例的宽屏实现：横屏改用常驻侧栏，页面纵向切换；宽屏阈值采用 `宽度 ≥ 840dp`，或 `宽度 ≥ 600dp 且高宽比 < 1.2`。窗口测量集中在 `ui/designsystem/CouiAdaptive.kt`，所有页面读取同一份 `CouiWindowMetrics`，不再各自硬编码尺寸。

| 窗口 | 侧栏宽度 | 页面左右留白 | 顶栏 | 阅读列上限 |
| :-- | --: | --: | :-- | :-- |
| 紧凑（< 600dp，含手机横屏） | 72dp | 16dp | 横屏 52dp 单行，竖屏大标题 | 不限制 |
| 中等（600–839dp） | 80dp | 20dp | 宽屏时 52dp 单行 | 首页 940dp、设置 720dp、关于 780dp、详情 860dp |
| 扩展（≥ 840dp） | 88dp | 24dp | 52dp 单行 | 同上 |

### 布局重排

- **导航**：`ArchiveApp` 在横屏或宽度 ≥ 600dp 时使用 COUI 原生 `NavigationRail`；详情、搜索、演唱会与作曲子页继续隐藏侧栏。侧栏只消费状态栏与底部导航栏的垂直 inset，水平安全区由页面统一处理，避免刘海和侧边手势区被重复留白。
- **介绍页**：专辑 / 演唱会 / 作曲胶囊固定在顶部。横屏时减少上下内边距、操作区固定为两个 48dp 按钮加 8dp 间距，胶囊高度与 `ArchiveScaffold` 预留的分区顶栏高度使用同一个公式，列表不会再出现 2dp 的上下错位。
- **顶栏**：宽屏与横屏的大标题页改用 52dp 单行 COUI 顶栏，避免短窗口被可折叠大标题占去过多高度；竖屏手机保持原有大标题。
- **关于页**：横屏的身份卡由近方形大卡片改为短横幅：标题、版号在左，检查更新胶囊在右；高度取窗口高度的 55% 并限制在 180–240dp。标题字号按可用宽度收敛到 32–44sp，避免横屏时被裁切。
- **列表与网格**：设置、首页、关于、演唱会使用居中的最大宽度阅读列；专辑、作曲网格按 `可用宽度 - 2 × 页面留白` 计算列数，横屏 560dp 宽时稳定为两列，扩展窗口保持五列左右。专辑详情限制在 860dp 内，歌词阅读保持原有 760dp 上限。

### 状态与切换

- 页面选择、介绍页分区、专辑 / 歌词详情、列表滚动位置仍由原有 `rememberSaveable` / `rememberLazy*State` 持有；横竖屏只改变测量与排列，不重建列表项，也不改变列表索引。
- 侧栏与底栏共用同一个 `PagerState`。从底栏切到侧栏时页面不跳转，返回竖屏后恢复底栏与当前页。
- 详情打开时旋转：详情保持打开、侧栏保持隐藏；返回后侧栏按新的窗口宽度恢复。
- 专辑封面共享元素动画以窗口比例的起点与实时布局终点计算，旋转后重新测量，不会回到旧尺寸。

### 适用范围与约束

- 适用于 Android 8.0+ 的 COUI 风格，包括手机横屏、平板横竖屏、折叠屏展开态和分屏窗口；Miuix 与 Material 3 的导航行为不变。
- 侧栏出现条件沿用项目原有规则（宽度 ≥ 600dp 或宽大于高），因此 560×360 的手机横屏也会使用侧栏，而官方示例的 600dp 分栏阈值只用于阅读列宽度。
- 为保证滚动位置与详情索引在旋转后一致，设置页与专辑详情不做列表 / 详情双栏拆分；横屏下通过居中限宽解决行长问题。
- 真实背景模糊与液态玻璃仍要求 Android 13+；旧系统使用实色表面。横屏适配不改变材质与采样实现。
- 大字体（font scale）下顶栏、胶囊和侧栏均可增长或滚动；关于页横幅使用 `heightIn(min = ...)`，内容变高时向下扩展而不是裁切。

### 预期效果

- 横屏首屏可见内容不被侧栏覆盖，也不超出左右安全区；介绍页胶囊、操作按钮和列表起点对齐。
- 宽屏上的正文行长受控，设置项、来源行和按钮不会被拉到整屏宽。
- 手机横屏的关于页不再被 300dp 以上的身份卡占满，标题、版号和更新入口在一屏内完整可见。
- 横竖屏来回切换后，当前页、分区、详情、滚动位置和选中状态保持一致，无布局错位、黑边或裁切。

验证入口：`CouiAdaptiveMetricsTest` 覆盖断点与尺寸；`CouiLandscapeTest` 覆盖手机横屏、扩展横屏、关于横幅、旋转后的选择 / 滚动保持以及详情开合。
