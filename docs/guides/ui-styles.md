# 三种界面风格

在「设置 → 主题风格 → 界面风格」选择 **Miuix、COUI（ColorOS）或 Material Design 3**。默认使用 Miuix，切换后即时生效并保留当前页面，无须重启。

## 风格与组件

| 风格 | 组件与表现 |
| :-- | :-- |
| Miuix | Miuix 0.9.3 主题与组件，支持高斯或渐变顶部模糊，以及可选玻璃导航。 |
| COUI（ColorOS） | COUI 1.1.0 主题与组件，采用超椭圆表面、分组设置、圆形操作按钮与分体悬浮底栏。 |
| Material Design 3 | AndroidX Material 3 1.4.0 主题与组件，提供原生导航、卡片、设置控件与动态配色。 |

三种风格共用专辑、演唱会、对外作曲、搜索与歌词业务流程，均可在应用支持的 Android 设备上选择。

## COUI 顶栏与材质

- 介绍页的专辑、演唱会与作曲标签固定在列表上方，滚动或左右切页时保持位置，操作区域只显示当前分区的按钮。
- 工具栏按钮与非液态玻璃的 COUI 悬浮底栏共用磨砂表面、描边和阴影；小顶栏为按钮阴影保留绘制空间。
- 开启模糊后，介绍页和专辑详情页使用向下渐隐的顶部模糊；绘制范围延伸到顶栏下方，保持内容位置与点击区域不变。
- 搜索页的按钮单独采样背景，避免把包含按钮自身的页面图层作为采样源。

实现与兼容说明见 [COUI 风格接入](coui-ui.md)。

## 设置保存

深浅色、动态配色、自定义颜色与专辑布局按风格独立保存。切回原风格时恢复原来的设置。

- Miuix 保留原有外观键。
- COUI 使用 `coui_` 前缀。
- Material 3 使用 `material3_` 前缀。
- `ui_style` 只记录当前选择，修改外观时只写入当前风格对应的字段。

悬浮底栏、液态玻璃、背景模糊、自定义背景、语言、个人资料、专辑分类、歌词导入和预测性返回等设置或数据共用。三种风格均提供模糊开关；Miuix 和 Material 3 可选择顶部高斯／渐变模糊。

Material 3 的模糊覆盖大小顶栏、介绍页标签栏、标准与悬浮底栏、宽屏侧栏、底部弹层、设置选择弹窗、关于页彩蛋及更新弹窗。卡片继续通过「背景 → 卡片模糊」独立控制，只采样自定义壁纸，保持文字与封面清晰。关闭模糊或低于 Android 13 时使用实色表面。

首次设置保存成功后，首页从完成页对号的实际中心以圆形展开，持续约 680ms。保存失败停留在完成页并允许重试；过渡期间屏蔽点击和返回，结束后保留同一首页实例，后续启动不重复播放。

## 导航与系统兼容

三种风格均支持标准底栏、悬浮底栏与可选液态玻璃。关闭液态玻璃时使用各自风格的导航；COUI 悬浮底栏由两侧圆形入口和中间胶囊组成。宽屏可使用对应风格的侧栏导航。COUI 在横屏下会收窄侧栏内边距、改用单行顶栏、限制阅读列宽度并将关于页身份卡改为短横幅；具体断点与约束见 [COUI 风格接入](coui-ui.md#横屏与宽屏适配)。

真实背景模糊与液态玻璃仅在 Android 13+ 创建采样与 shader 对象；旧系统保留实色表面。动态配色要求 Android 12+。

## 代码入口

- `ui/theme/ArchiveTheme.kt`：选择风格主题；`CouiArchiveTheme.kt` 与 `MaterialArchiveTheme.kt` 分别处理对应配色。
- `ui/designsystem/`：共享页面的组件与主题适配，业务页面共用同一数据与交互流程。
- `ui/components/ArchiveScaffold.kt`：顶栏、顶部安全区与分区操作。
- `ui/navigation/`：标准底栏、悬浮底栏、液态玻璃与侧栏导航。
- `ui/effects/`：背景采样、COUI 磨砂表面与顶部渐变模糊。
- `data/SettingsRepository.kt`：风格选择与外观设置的持久化。

相关回归测试包括 `UiStyleSwitchTest`、`UiStylePersistenceTest`、`CouiToolbarLayoutTest` 与 `AlbumSearchNavigationTest`。


## 设置页面层级

设置首页的“外观”卡片提供带图标的“主题”“语言”“动画与手势”入口。语言保留原生下拉选择；主题与动画分别打开二级页面。

“主题”集中专辑浏览布局、界面风格、悬浮导航栏、液态玻璃、明暗模式、Monet、模糊、自定义颜色和背景设置。“动画与手势”集中页面过渡说明及预测性返回开关。更新设置保留在首页。

二级页隐藏主导航，通过标题栏或系统返回回到设置首页；首页、主题与动画页面分别保留滚动位置，页面选择参与状态恢复。


## 二级页面动效与 GD3 设置样式

`SecondaryPageHost` 保留父页面与退出中的子页面，统一设置详情、创作详情、演唱会详情与专辑搜索的进入、退出和 Android 14+ 预测性返回。手势支持左右边缘、跟随触点的缩放中心和取消回弹；导航栏在退出完成后恢复。专辑与歌词继续使用独立封面飞行动画，同时共用返回手势的页面变换。

“动画与手势”提供无、AOSP、Miuix、缩放和经典五种返回样式，使用全局 `predictive_back_animation` 字段保存；旧配置默认缩放，原有预测性返回开关保持有效。低于 Android 14 时使用普通进入/退出过渡。

GD3 设置采用大圆角分组、2dp 行间隙、色调表面、主色选中项、界面风格单选列表和带勾选拇指的开关。二级页采用圆形返回按钮；COUI 二级页使用与专辑详情相同的紧凑顶栏和渐进模糊。

设计与手势参考：[InstallerX-Revived](https://github.com/wxxsfxyzm/InstallerX-Revived)，包括 `BaseWidget.kt` 的分组列表思路与 `ScaleNavTransition.kt` 的缩放中心设计；项目内实现适配现有 Compose 页面状态与封面动画。


二级设置页的固定顶栏不接入大标题栏的折叠滚动连接，避免拖动和 fling 被无实际折叠区域的滚动行为消耗；底部留白包含系统导航栏安全区。退出方向提供“跟随手势 / 始终向右 / 始终向左”，使用 `predictive_back_exit_direction` 保存，默认保持跟随手势。方向作用于页面最终退出，缩放中心仍跟随真实手势边缘；正常进入始终从右侧进入。

从设置详情、搜索、演唱会/创作详情及专辑详情返回一级页面时，底部栏在重新可见后执行 320ms 向上滑入并淡入，滑动距离取实际底栏高度，兼容标准底栏、悬浮底栏及液态玻璃。切换一级标签不重复播放该动画。


专辑/歌词的封面飞行层与页面退场层互为同级：封面在独立坐标空间内缩放、回到列表或歌曲缩略图，页面表面与正文继续按所选退出方向离场。封面终点用页面局部坐标测量，避免页面位移/缩放反复改变封面路径；预测性返回期间也分离封面，取消手势后将封面还原到详情位置。
