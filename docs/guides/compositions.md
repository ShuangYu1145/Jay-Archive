# 对外作曲目录

介绍页的「作曲」标签按歌曲展示周杰伦为其他歌手创作的作品。沿用专辑布局设置（列表、网格、大封面），每种布局独立保存滚动位置。支持简繁体歌名、歌手、发行名称与年份组合搜索，点击歌曲查看作曲、作词、演唱者、发行资料及来源。

`app/src/main/assets/compositions.json` 保存独立目录，不计入周杰伦个人专辑及曲目统计。初始整理了 170 首作品，参考[周杰伦创作作品列表固定版本](https://zh.wikipedia.org/w/index.php?title=周杰倫創作作品列表&oldid=92753603)，提取名称、人员、日期等事实字段，不收录歌词或百科正文。不宣称覆盖全部作品；来源列表本身可能存在遗漏，后续可根据唱片公司资料逐项补充、修订。

日期对应目录列出的发行版本，不一定是歌曲最早发表日期。比如《屋顶》保留吴宗宪与温岚的版本，《世界末日》保留咻比嘟哗的版本，而不是周杰伦后来演唱的版本。原文、简体显示与搜索字段均保留；非中文界面保留作品原名，界面文案通过五语资源生成器维护。

封面从 Apple Music 台湾目录按歌曲名及演唱者匹配，可能来自再版或精选数字发行；`artworkSourceUrl` 记录具体歌曲来源。未匹配时显示主题色唱片图案，不借用周杰伦个人专辑封面。封面仅使用在线地址，由图片加载器缓存，不在 APK 内打包离线副本。维护脚本 `scripts/fetch_composition_artwork.py` 可在 Windows 手动运行，构建与应用启动不执行该脚本，也不联网获取歌曲目录。

`CompositionTest` 验证目录、版本、搜索及封面文件；`CompositionsNavigationTest` 验证两套界面风格、三种布局、搜索、详情和返回。
