# 3D 专辑墙

在「设置 → 外观 → 专辑浏览 → 专辑布局」选择「3D 专辑墙」。该选项沿用各 UI 风格原有的设置持久化；默认布局保持不变。分类筛选、搜索和专辑详情导航沿用现有流程。

核心组件为 `ui/components/AlbumCoverFlow.kt`：

```kotlin
AlbumCoverFlow(
    albums = filteredAlbums,
    onAlbum = onAlbum, // 原有 (Album, AlbumOrigin) -> Unit 详情导航
    modifier = Modifier.fillMaxSize(),
    onSelectedAlbum = { album -> /* 吸附完成后的可选通知 */ },
)
```

组件需要有界的宽高。它直接消费 `List<Album>`，使用稳定的 `Album.id` 维护选中项；列表重排保留选中身份，选中项被移除时回到首张。空列表和单张列表均支持，重建后恢复最近的选中专辑。当前目录是周杰伦的专辑档案，模型没有专辑歌手字段，因此信息区使用本地化的周杰伦名称，不将歌曲合作艺人误当作专辑艺人。

封面统一为正方形，原图以 `ContentScale.Crop` 居中裁切，保留比例、铺满正方形。CD 盒不是一张旋转图片：`CdCaseGeometry` 计算正面、背壳、书脊和顶面的共享三维顶点，实体厚度是边长的 6.5%。绕 Y 轴旋转到 ±66° 时，书脊和壳体厚度会自然显露；上下方向也有轻微透视。正面居中时保持完整的正方形。

`CdCaseArtwork` 将原有 `CatalogImage` / Coil 内容记录到 GPU `GraphicsLayer`，用每个面的四点透视矩阵绘制。壳体有塑料封边和带专辑名称的书脊，不绘制底部接触阴影，避免多个阴影叠成贯穿专辑墙的横线。没有逐帧转成位图，也没有依赖 Android 对平面投射的夸张阴影。图形对象和投影数组按尺寸缓存，位置变化只触发布局与绘制；点击也使用同一套实体顶点命中测试，避免旋转图形外接矩形误判。

背景、文字与显示控制使用 `ArchiveUiTheme` 颜色，因此 MIUIX、COUI、Material 三套风格均随浅色/深色主题切换。横竖屏根据可用宽高确定封面大小，元信息紧邻专辑墙。

右上角的「显示设置」按钮可分别关闭顶栏及底部导航栏（横屏为侧边导航）。隐藏后释放原有的内容预留空间，按钮始终保留，便于再次显示。返回键可以恢复两栏；打开专辑详情后再返回仍保留隐藏状态，下一次返回才退出沉浸浏览。隐藏选择通过 `rememberSaveable` 保持到 Activity 重建，不影响其他页面。系统状态栏和手势安全区域仍按系统 Insets 避让。

显示设置弹层从入口的右上角淡入、缩放展开，退出动画完成后才销毁。入口复用搜索/筛选的工具栏材质，浮层按钮采样的背景只包含专辑墙，避免把按钮自身反复采进磨砂材质。

详情返回中，手势预览系数与退场进度相乘，使封面和背景直到退场结束才抵达零，避免松手后封面提前停在终点。转场图片与图形层在详情打开期间保留待命，返回时只更新图层属性，减少首帧重新组合和创建图片请求的开销。

拖动通过 Compose `ScrollableState` / `scrollable` 消费像素距离，惯性投影决定最终索引，临界阻尼弹簧完成吸附。点击、拖动与惯性共用滚动互斥锁，新手势取消旧动画，避免并发写入位置。仅组合可见邻域；每帧位置在布局放置阶段读取，只有最近索引变化时才更新信息区和邻域。组件销毁会取消协程，保存的状态只包含专辑 ID，不保存图片或图形层。

「为他人创作」页面共用布局设置，但内容模型是作品集合，选择专辑墙时使用现有单列作品布局。

验证：

- `CdCaseGeometryTest`：中心正方形、双向旋转后的实体书脊面积及共享边缘。
- `CoverFlowPresentationTest`：三套风格的明暗主题与横竖屏截图、非正方形图片无留边、隐藏两栏及侧栏空间释放、详情返回与按钮恢复。
- `CoverFlowScrollTest`：边界消费、反向拖动、空列表和单张列表。
- `AlbumCoverFlowTest`：侧封面选择、中央详情回调、状态恢复、重排及移除、动画中手势打断与反向吸附。
- `AlbumTransitionProgressTest` / `CoverFlowReturnMotionTest`：手势提交后末段持续移动、终点一致，以及显示弹层的展开和退出动画。
- 现有网格布局恢复测试继续覆盖三个网格/列表布局；专辑墙的状态恢复由专用测试覆盖。

模拟器交互测试不能替代实体设备上的帧率测量。远程封面加载受网络影响，仍沿用项目的图片加载状态、错误状态和重试机制。
